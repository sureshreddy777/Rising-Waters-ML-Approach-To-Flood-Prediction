Prediction Model Details

Technical details about the machine learning implementation

Machine Learning Models Used
Decision Tree

A tree-based model that makes predictions by learning simple decision rules inferred from data features.

Random Forest

An ensemble method combining multiple decision trees for more robust and accurate predictions.

K-Nearest Neighbors

A simple, instance-based learning algorithm that classifies based on nearest neighbors in the feature space.

XGBoost

Primary Model: Gradient boosting framework providing superior accuracy for flood prediction.

Model Performance Metrics
Metric Description
Accuracy Overall correctness of predictions
Precision True positive predictions out of all positive predictions
Recall True positive predictions out of all actual positives
Confidence Score Probability associated with the prediction
Interpretation Guide
High Risk: The model predicts a high probability of flooding. Emergency preparedness measures should be considered.
Low Risk: The model predicts a low probability of flooding. Normal conditions are expected.
